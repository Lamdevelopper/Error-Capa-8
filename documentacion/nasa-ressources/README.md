# NASA Human Spaceflight Risks

Índice local de la página de riesgos del Human Research Program (HRP) de NASA y sus fichas individuales enlazadas. Las descripciones están resumidas en español; los enlaces llevan a la fuente primaria para consultar el contenido completo y actualizado.

**Fuente índice:** [About Human Spaceflight Risks](https://www.nasa.gov/hrp/risks/)  
**Consultado:** 2026-11-14  
**Actualización indicada por NASA para el índice:** 2026-07-21

## Alcance y uso

NASA organiza aquí riesgos de salud y desempeño asociados con los peligros del vuelo espacial. El índice enlaza 16 riesgos en tres grupos. Esta carpeta sirve como referencia documental para el proyecto; no contiene datos de astronautas, un dataset descargado, recomendaciones clínicas ni reglas/umbrales para alertas.

Los resúmenes son paráfrasis breves del texto descriptivo del índice NASA. Para evidencia técnica detallada, consultar además la descripción formal y la investigación reciente enlazadas desde cada ficha de NASA. No inferir diagnóstico, causalidad individual, prevalencia o umbrales a partir de estas síntesis.

## Peligros relacionados

La página índice remite a los [cinco peligros del vuelo espacial](https://www.nasa.gov/hrp/hazards/): radiación espacial, aislamiento y confinamiento, distancia de la Tierra, campos gravitatorios y ambientes hostiles/cerrados. Un riesgo puede estar relacionado con varios peligros; esta carpeta no pretende establecer una relación causal completa entre ellos.
