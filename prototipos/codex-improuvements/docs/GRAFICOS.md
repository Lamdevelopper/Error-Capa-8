# Gráficas de mediciones

Cada gráfica usa las muestras suministradas por la fuente. Los datos importados se sitúan por fecha y hora de captura; la demostración muestra sus pasos, sin presentarlos como horas reales. Los ejes muestran la unidad de la métrica y una escala calculada a partir de los valores disponibles, sin bandas clínicas supuestas.

La presión muestra ambas series cuando se dispone de ellas, y una ausencia interrumpe la línea secundaria. Movimiento y duración del sueño se muestran como barras; si llegan fases de sueño registradas, se muestra su cronología real. No se generan fases a partir de una duración. Una lectura aislada se muestra como una sola muestra; si no hay datos se informa de ello.

En la vista ampliada se puede recorrer el historial con el puntero o las flechas del teclado; la fecha o paso y el valor seleccionado aparecen debajo. Los datos de demostración siguen siendo simulados y no representan observaciones clínicas.
